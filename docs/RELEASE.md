# 微截 1.5.0-preview

本轮统一界面并修复快捷键、工具条与保存问题，同时把 PP-OCRv6 切换为 ncnn Vulkan 全模型推理。

## 快捷键与工具条

- 工具条中与绿色「完成」重复的「复制并退出」按钮改为齿轮「设置」：点击后关闭覆盖层并打开设置窗口。
- 全局快捷键增加 `WH_KEYBOARD_LL` 低级键盘钩子与 `GetAsyncKeyState` 轮询兜底，
  部分游戏 / 全屏 UI 占用键盘焦点时也能触发截图。
- 窗口吸附改为按 `EnumWindows` 的 Z 序寻找光标下顶层窗口，过滤不可见、最小化、DWM cloaked、
  tool window、透明覆盖层和桌面壳层；悬停显示绿色轮廓，不拖拽直接点击即可截取整窗。
- 工具条新增「表情」工具，内置 88 个由 Segoe UI Emoji COLR/CPAL 色彩层生成的彩色 Emoji；
  选择后点击选区即可插入，支持撤销/重做。
- 修复工具滑块拖拽时的轨迹残影、断线和缩略图跳动：滑轨改为连续填充绘制，并在滚动时
  主动重绘滑块，避免原生 tick/动画残影。

## 设置与保存

- 修复设置页切换后，截图快捷键输入框透出上一页翻译提示文字、背景残留的问题。
- 翻译服务新增主开关；OCR 或翻译主开关关闭时，截图工具条隐藏对应的识别 / 翻译按钮，
  提取文字结果面板也同步隐藏「翻译」按钮，只保留「复制 / 关闭」。
- 「保存」按钮与 `Ctrl+S` 直接保存到设置中的保存位置并自动生成不冲突的文件名，不再弹出文件夹选择。
- PP-OCRv6 改用 ncnn Vulkan 运行时，检测 / 方向分类 / 识别全模型走 Vulkan，兼容 Intel / AMD / NVIDIA；
  无可用 Vulkan 设备时自动回退 CPU。基础包不内置组件，需在设置「文字识别」页点击
  「下载 OCR 组件和 PP 模型」，组件会安装到 `%LOCALAPPDATA%\weijie\ocr-ncnn`。

## 界面更新

- 七类工具右键面板：统一白色圆角卡片、绿色滑轨、数值徽标、上下限和对应工具预览。
  文字展示文字预览，序号展示圆形标记，马赛克展示像素块，不再一律用直线代替。
- 颜色面板：近期颜色与默认色、圆角 HSV 调色盘、彩色色相条、透明度棋盘条、
  HEX 输入、实时预览、统一的绿色完成按钮。
- 设置：侧边导航 + 分组卡片；输入框、下拉框、滑块、勾选框、下载进度和按钮使用共同样式。
- OCR 结果面板：统一白色底、边框、标题层级和文本边距；正文改用不透明白色背景并在滚动时
  主动擦除旧文字，三十行以上长文本来回滚动不会再出现文字重影。
- 系统保存对话框及警告提示继续保留系统原生行为。

## 修复用户截图中的错位

175% DPI 下，自绘后台位图曾被 GDI+ 按图片 DPI 再缩放一次，背景与原生控件因此错位，
并产生切页残影。现在所有新增后台画布均显式设置像素坐标和输出宽高，不再使用
按图片物理尺寸绘制的重载。新画布也带有对应 DPI 元数据，回归快照覆盖 100% / 175%。

## 验证

- 原生 UI 离屏渲染：22 张快照（设置三页、七个工具、颜色面板，100% / 175%）。
- 设置页显隐、导航、JPEG 滑块：通过。
- 七个工具滑块、HEX 解析、透明度：通过。
- 核心 CPU OCR 测试：33 项通过。
- 核心 GPU OCR 测试：33 项通过。
- 本轮系统窗口截图通道返回 `window capture timed out`，因此不能将离屏快照当作
  对所有实际显示环境的完整实屏验收。用户提供的错位截图对应的缩放路径已修正。

测试结果与预览图位于 `Release/verification`。源码位于仓库 `cpp/`，不再重复堆放在程序目录。

## 使用

运行本目录 `微截.exe`，或 `设置.lnk` / `一键截图.lnk`。
退出旧实例再运行新版；原设置、快捷键、模型目录与历史颜色保留，不自动更换推理设备。

主程序仍为原生 C++；`ocr-ncnn` 是 PP-OCRv6 / ncnn Vulkan 本地推理组件，
由设置页按需下载。混元 Q8 模型及其 mmproj 的下载地址保持不变；
关闭 OCR 后仍隐藏截图工具条中的识别和翻译按钮。

非腾讯官方软件，不是微信截图的完整 1:1 复刻。程序仍位于 Windows Temp，
长期使用请把整个文件夹复制到固定位置并重建快捷方式。
