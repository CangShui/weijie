# 微截 1.6.0

本版完善 D3D 游戏截图、OCR 生命周期、图片素材分组、动态贴图、标注移动与截图唤起性能。

## 本版亮点

- 八类标注统一支持右键拖动和重叠对象循环选择，普通左键继续绘制或放置新图案。
- 文字编辑框支持独立拉伸、旋转、移动和逐步撤销/重做；文字工具不再改变系统鼠标指针。
- `images` 支持任意图片、GIF 动态贴图、子文件夹分组和目录热刷新，保存时可选择动态 GIF。
- OCR 主开关关闭立即卸载模型，空闲回收支持 off 至 24 小时六档配置。
- 管理员登录任务开机启动，托盘注册在通知区域未就绪时自动重试，任务栏重建后恢复图标。
- D3D 截图复用图形设备，多屏共享等待预算；本机后续抓屏中位耗时由 140ms 降至 62ms。
- 截图保存目录、另存为、长截图保存和剪贴板结果均给出明确反馈，不把成功写盘误报为失败。

## 截图唤起性能

- 后续截图复用 D3D 设备，仅为实际连接桌面的适配器创建设备。
  不保留桌面复制会话、staging 纹理或旧画面，不在后台持续抓屏；设备失效或适配器列表改变后重建。
- 多屏非阻塞轮询取帧，共享 300ms 等待预算，避免多个静止副屏的超时串行累积。
  保留实际桌面图像校验、旋转屏、负坐标、按屏 GDI 回退及系统保护画面遮蔽。
- 设置在一次唤起中只读取一次；窗口吸附探测在覆盖层显示前完成，
  首次绘制直接包含高亮，输入接管完成后显示首帧。
- 同一截图追踪日志记录快捷键消息排队、托盘双击/快捷入口来源和各阶段耗时，
  可区分显卡初始化、等帧、复制、窗口探测及输入接管造成的延迟。

本机单屏 2560×1440 的抓屏阶段基准，每组 1 次首次抓屏及 5 次后续抓屏：

| 场景 | 优化前 | 优化后 |
|---|---:|---:|
| 首次抓屏 | 157ms | 157ms |
| 后续抓屏中位数 | 140ms | 62ms |
| 后续抓屏范围 | 125–156ms | 47–63ms |

### 已知限制

首次抓屏仍受显卡驱动初始化影响，设备复用主要减少后续调用成本。
300ms 仅限制共享等帧阶段，驱动调用、图像复制和窗口显示另计；基准不代表所有设备的完整唤起时间。
当前实屏回归遇到更高权限前台，输入接管用例跳过；管理员游戏中的物理快捷键需实机验收。

## D3D 游戏截图

- 主程序默认请求管理员权限，手动运行时由 Windows 显示 UAC 授权，以便接管管理员游戏的截图输入。
- 「开机自动启动（管理员权限）」使用当前用户登录计划任务，以最高权限运行，不保存密码，
  不使用 SYSTEM 或非交互会话。旧版注册表启动项在启动新版时自动转换，关闭开关会移除任务。
- 管理员登录任务支持电池供电和持续常驻，避免默认任务策略中断截图工具。
  配置失败会显示原因，任务开关不会静默失效；移动程序后需重新勾选开关更新路径。
- 开机登录时通知区域尚未就绪，托盘图标每 2 秒重试注册，成功后停止重试，不延迟截图快捷键。
  隐藏的后台窗口接收任务栏恢复广播，允许 Explorer 通知管理员实例；任务栏重建后自动恢复图标。
  注册、失败重试、恢复和退出清理使用同一操作追踪编号记录到运行日志。
- 热键增加后台 Raw Input，独立维护左右修饰键、按下和释放状态；不拦截游戏输入，不记录普通按键。
- 游戏画面优先通过 DXGI Desktop Duplication 抓取，兼容旋转屏、负坐标副屏和多显卡输出；
  等待实际桌面图像而非仅有光标更新的帧通知，单屏无法使用 DXGI 时为该屏回退 GDI。
- 覆盖层先取得前台，再解除游戏鼠标限位并显示光标；无法接管输入时关闭覆盖层并记录失败，
  不再把窗口创建成功当作截图已可操作。覆盖层退出时配对恢复光标显示计数。
- 截图链路日志按同一 `traceId` 记录请求、权限拒绝、各屏抓取、输入接管、完成和异常分支，
  写入 `%LOCALAPPDATA%\weijie\logs\audit-dev-YYYY-MM-DD.log`。

### 验证游戏截图

```bat
build.bat -Task Test -Suite Core
build.bat -Task Test -Suite Capture
```

`Capture` 创建 D3D11 测试窗口，覆盖原始键盘包分发、鼠标限位、光标可见性、冻结帧、
重复请求和 Esc 退出。前台程序权限更高时，会标明输入测试跳过，需在管理员终端运行完整测试。
结果保存在 `Release\verification\capture-tests.txt`。

### 已知限制

手动启动需要确认 Windows UAC；开机启动在用户登录后运行，需先在新版中启用或完成旧启动项转换。
系统保护画面仍由 Windows 遮蔽。游戏内物理热键与反作弊环境需要实机验收。

## 快捷键与工具条

- 工具条中与绿色「完成」重复的「复制并退出」按钮改为齿轮「设置」：点击后关闭覆盖层并打开设置窗口。
- 全局快捷键增加 `WH_KEYBOARD_LL` 低级键盘钩子与 `GetAsyncKeyState` 轮询兜底，
  部分游戏 / 全屏 UI 占用键盘焦点时也能触发截图。
- 设置窗口打开时仍可触发截图并保留未保存内容；仅在快捷键录入框获得焦点时暂停触发。
  设置窗口的消息过滤和缩放不影响截图覆盖层，Esc 关闭截图后设置窗口继续保留。
- 窗口吸附改为按 `EnumWindows` 的 Z 序寻找光标下顶层窗口，过滤不可见、最小化、DWM cloaked、
  tool window、透明覆盖层和桌面壳层；悬停显示绿色轮廓，不拖拽直接点击即可截取整窗。
- 工具条「表情」读取主程序旁的 `images` 文件夹，随包附带默认素材，用户可自行增删。
  支持 JPG/JPEG、PNG、GIF、BMP、TIF/TIFF，GIF 支持动画；不读取旧 `emoji` 或用户数据素材目录。
  子文件夹按各自目录分组，`images/default` 显示为“默认”，根目录图片显示为“未分类”，
  嵌套目录使用相对路径作为组名。默认组在前、未分类在后，组内按文件名排序。
  每次打开重新扫描，窗口打开期间也监听目录变化并刷新；支持滚轮、滚动条和 PageUp/PageDown 浏览。
  损坏文件跳过并记日志，空目录显示添加图片提示。
- 缩略图、鼠标虚影和落地图片共用等比缩放逻辑，尺寸受软件设置约束，不由原图分辨率决定。
  目录只保留小缩略图，选中后按最大放置尺寸加载大图缓存并释放源文件；
  目录更新不影响已放置图片，支持撤销/重做。
- 默认素材位于 `images/default`。删除文件会移除图片条目，删除文件夹会移除整个分组，
  空目录保留空分组。默认素材可全部删除，程序、构建和后续部署均不自动补回。
  首次升级仅移动旧版仍存在的默认图标，保留用户修改和删除；根目录自定义图片保持“未分类”。
- 修复工具滑块拖拽时的轨迹残影、断线和缩略图跳动：滑轨改为连续填充绘制，并在滚动时
  主动重绘滑块，避免原生 tick/动画残影。

## 设置与保存

- 动态 GIF 贴图保留每帧间隔，支持透明背景、局部帧偏移、恢复背景和恢复上一帧。
  悬停缩略图、鼠标虚影、截图画布、贴图及长截图预览可播放动画，只在帧变化时更新。
- 所有保存和另存为入口在存在动态贴图时询问：是则输出 GIF，否则按静态格式输出各贴图首帧，
  取消保留界面。混合动画的总时长为最长贴图时长，短动画循环；整体输出无限循环。
  `Ctrl+Shift+S` 提供截图另存为，剪贴板仍使用首帧静态图。
- GIF 首帧保存完整背景，后续只编码变化矩形，矩形内未变化像素使用透明索引，
  重复帧合并时长，使用共享自适应 256 色调色板和 LZW 压缩。
  超长停顿以单像素延时帧维持，不重复写入背景。编码失败不覆盖已有文件；文件尺寸受 GIF 边界限制。
- 滚动截图移除最多 24 次滚动和固定 20,000 像素高度限制；页底连续三次无变化时完成，
  按 Esc 可提前结束并保留预览。窗口切换、无法继续匹配及达到 200 MiB 像素缓存上限
  均保留已拼接内容，并在预览显示结束原因。当前编码器的 65,535 像素高度边界
  同样会明确提示，保留可保存的长图。
- 长截图预览的「保存」直接写入设置目录，显示实际保存路径；新增「另存为」独立选择
  路径和格式。另存为取消、保存失败均保留预览；设置目录不可用时仍可另存到其他目录。
- 图片保存以本次编码结果为准，不因位图此前操作的错误状态拒绝保存；长图预览仅绘制
  当前可见区域。保存与自动复制分别报告结果，日志记录目录、实际文件及编码状态。
- JPEG 超出格式尺寸上限时提示另存为 PNG / BMP，保留预览。

- 「文字识别」增加「空闲自动回收」下拉框：`off`、`1分钟`、`10分钟`、
  `1小时`、`12小时`、`24小时`。默认 `off`，保存后生效；最后一次识别结束后
  开始计时，超时释放缓存模型的内存与显存，不打断正在执行或排队的调用。
  自动回收保留识别主开关，下次调用按需加载。

- 修复设置页切换后，截图快捷键输入框透出上一页翻译提示文字、背景残留的问题。
- 「启用文字识别（主开关）」同时控制识别按钮和模型生命周期。关闭立即中止识别，
  终止本程序持有的 PP-OCR 或混元模型进程，释放模型内存与显存，不等待推理完成。
- 主开关关闭后，图片翻译不会重新加载 OCR 模型；翻译按钮独立显示，已有文字仍可直接翻译。
  重新开启并保存后，下次识别按需加载，连续识别保持复用。取消设置恢复原权限但不预加载。
- 组件在实际执行时检查，保存主开关、保存目录等设置不要求先安装组件。
- 「保存」按钮与 `Ctrl+S` 直接保存到设置中的保存位置并自动生成不冲突的文件名，不再弹出文件夹选择。
- PP-OCRv6 改用 ncnn Vulkan 运行时，检测 / 方向分类 / 识别全模型走 Vulkan，兼容 Intel / AMD / NVIDIA；
  无可用 Vulkan 设备时自动回退 CPU。基础包不内置组件，需在设置「文字识别」页点击
  「下载 OCR 组件和 PP 模型」，组件会安装到 `%LOCALAPPDATA%\weijie\ocr-ncnn`。

## 界面更新

- 八类标注统一支持右键拖动，普通左键只绘制或放置新图案，允许重叠标注。
  原地右键单击按从上到下的顺序循环选择重叠对象，选中后显示轮廓和操作提示，
  拖动优先移动已选对象，不改变图层顺序。移动超过 4 个逻辑像素后才进入拖动。
  工具按钮的右键拖动及画布空白处的右键拖动继续调整后续标注尺寸。
  方向键微调已选图案；每次移动可独立撤销/重做，Esc、失焦或捕获转移取消当前拖动。
  图案命中、选择、拖动、拒绝、取消及完成沿用同一截图追踪编号落盘记录。
- 文字增加可编辑变换框：八个控制点独立拉伸宽高，顶部手柄自由旋转，
  对侧锚点及旋转中心保持固定。输入期间调整后继续编辑，双击已完成文字可重新编辑并保留变换。
  完成输入后使用右键移动文字，右键选中或移动时只显示移动外框，不显示或响应拉伸旋转点。
  松开右键不自动重新进入编辑；双击文字后显示编辑框和控制点。
  在已有文字上普通左键可新建输入框；文字输入框的边框、拉伸和旋转操作保持不变。
- 标注历史统一记录新增、修改、删除，文字移动、拉伸、旋转及内容编辑分别支持撤销/重做。
  变换中 Esc、失焦、捕获转移会恢复原状并释放鼠标；控制框、光标和手柄不进入输出图片。
  GIF 调色板基于各时段实际叠加后的颜色采样，保留旋转文字与半透明贴图交叠的颜色。
- 文字工具统一使用系统普通箭头，不创建随字号变化的 I 形鼠标，保持工具条和其他按钮的精确点击位置。
  放置文字、输入和调整字号均不放大鼠标；文字框中的输入竖线及中文组合下划线继续按字体行高绘制。
  真正编辑文字时，边框、拉伸控制点和旋转手柄保留对应操作指针；导出不包含鼠标和输入竖线。
- 序号、表情增加随指针移动的半透明落点虚影，复用真实标注的尺寸和绘制，
  中心与点击落点一致。序号预览下一编号，悬停不消耗编号；大小、颜色、表情及撤销/重做
  同步更新预览。虚影只显示在可放置区域，避开控件，不参与保存和复制；
  移动只更新独立小窗口，不重绘整张截图。
- Emoji 使用右键按住并左右拖动调整大小，支持工具栏图标和画布空白处，范围 12–256，
  新插入表情采用所选大小，已有表情不变。
- 表情选择在鼠标抬起后完成，恢复覆盖层焦点和放置按键状态；
  选择后移回选区即可显示虚影，不需要额外点击。鼠标在其他窗口松开后返回，
  同样恢复落点虚影，不会因遗漏抬起事件一直隐藏。
- 八类标注大小取消独立窗口，改为工具图标右键按住拖动：左小右大，按下显示内联滑条，
  松开确认并收起。整数数值未变时滑块仍逐像素跟随；已有标注不变。
  `Esc` 撤销本次调整但不关闭截图，失焦、捕获转移和取消操作会恢复原值并释放鼠标。
  拖动只标记滑条区域重绘，内联滑条不参与导出；画布空白处同样支持已选工具的右键尺寸调整。
- 颜色、透明度和 JPEG 画质保留自绘滑条的轨道点击、滑块拖动和键盘调整，
  越界松开或取消均释放鼠标。
- 画笔、马赛克增加随鼠标移动的圆形尺寸光标；画笔显示当前颜色，马赛克显示棋盘图案。
  直径与实际笔刷使用同一截图像素尺寸，调整 px 同步更新，高 DPI 下保持物理像素一致。
  预览不进入导出图片；离开选区、进入工具条或切换其他工具时恢复普通指针。
- 八类工具使用绿色内联滑轨、数值徽标和上下限，不再创建大小面板；
  颜色与透明度面板保留颜色预览。
- 颜色面板：近期颜色与默认色、圆角 HSV 调色盘、彩色色相条、透明度棋盘条、
  HEX 输入、实时预览、统一的绿色完成按钮。
- 设置：侧边导航 + 分组卡片；输入框、下拉框、滑块、勾选框、下载进度和按钮使用共同样式。
- OCR 结果面板：统一白色底、边框、标题层级和文本边距；正文改用不透明白色背景并在滚动时
  主动擦除旧文字，三十行以上长文本来回滚动不会再出现文字重影。
- 系统保存对话框及警告提示继续保留系统原生行为。

## 修复用户截图中的错位

175% DPI 下，自绘后台位图曾被 GDI+ 按图片 DPI 再缩放一次，背景与原生控件因此错位，
并产生切页残影。现在所有新增后台画布均显式设置像素坐标和输出宽高，不再使用
按图片物理尺寸绘制的重载。新画布也带有对应 DPI 元数据，回归快照覆盖 100% / 175%。

## 使用

运行本目录 `微截.exe`，或 `设置.lnk` / `一键截图.lnk`。
退出旧实例再运行新版；原设置、快捷键、模型目录与历史颜色保留，不自动更换推理设备。

主程序仍为原生 C++；`ocr-ncnn` 是 PP-OCRv6 / ncnn Vulkan 本地推理组件，
由设置页按需下载。混元 Q8 模型及其 mmproj 的下载地址保持不变；
识别按钮按识别主开关显示，翻译按钮按翻译显示开关显示；关闭识别主开关会卸载模型。

非腾讯官方软件，不是微信截图的完整 1:1 复刻。
发布包可直接解压到固定目录使用；安装目录实例由管理员登录任务启动。
