# 微截 · 源码仓库

原生 C++20 / Win32 / GDI+ 截图工具。基础产物不包含 OCR 组件；
用户在设置「文字识别」页点击下载后，才会把 PP-OCRv6 small + ncnn Vulkan
组件和模型安装到 `%LOCALAPPDATA%\weijie\ocr-ncnn`。

「文字识别」页的「空闲自动回收」可选 `off`、`1分钟`、`10分钟`、`1小时`、
`12小时`、`24小时`，默认 `off`，保存后生效。从最后一次识别结束开始计时，
空闲超时释放缓存模型的内存与显存，不中断正在执行或排队的识别。
回收不关闭识别主开关，下次调用按需加载；主开关关闭仍立即停止识别并卸载模型。

仓库：<https://github.com/CangShui/weijie>

## 目录

```text
assets/                     图标与源素材
cpp/src/                    当前原生 C++ 源码
cpp/tests/                  核心测试与原生 UI 快照测试
cpp/ocr-ncnn/               PP-OCRv6 ncnn sidecar 源码
runtime/weijie-ocr-ncnn.zip PP-OCRv6 small + ncnn Vulkan 组件与模型（设置页下载源）
runtime/ocr-ncnn/           开发机解压后的 OCR 组件（本地测试用，不入库）
runtime/images/default/     默认图片素材（可删除、可添加其他分组）
docs/                       发布说明、源项目文档
scripts/                    构建、运行、打包脚本
legacy/                     旧 Python 版源码（历史保留）
Release/                    构建产物目录
```

## 构建

```bat
build.bat -Task Build
build.bat -Task Test -Suite CPU
build.bat -Task Test -Suite GPU
build.bat -Task Test -Suite UI
build.bat -Task Test -Suite Capture
build.bat -Task Test -Suite Lifecycle
build.bat -Task Deploy
```

`-Task Build` 生成最小运行包 `Release\weijie\微截.exe`，不复制 OCR 组件。

`-Task Deploy` 关闭 `C:\Program Files\weijie` 中的实例、替换可执行文件，再以管理员身份启动新版本。
开机时托盘尚未就绪会每 2 秒重试注册，任务栏重建后自动恢复图标，不影响截图快捷键。
需要更换安装目录时直接运行 `scripts\deploy-installed.ps1 -Target <目录>`。
CPU / GPU 测试会自动从 `runtime\weijie-ocr-ncnn.zip` 解压组件到测试目录，
测试结束后再移除，保证最终发布目录仍然是最小产物。

输出结构：

```text
Release/weijie/             最小运行包：微截.exe、images、快捷方式
Release/Tests/              核心测试和 UI 测试程序
Release/verification/       测试日志、UI 快照
Release/.build/             编译中间文件，可安全清理
Release/archives/           可选 ZIP 包
```

## 游戏内截图

运行 `Release\weijie\微截.exe`，确认 Windows 的管理员授权后，
回到游戏按设置中的截图快捷键。程序默认请求管理员权限，无需每次右键选择「以管理员身份运行」。

- 热键使用系统热键、低级钩子、异步轮询和后台 Raw Input，多个来源合并为一次截图。
- 抓屏优先使用 DXGI Desktop Duplication，按显示器拼接；单屏失败时为该屏回退 GDI。
- 先冻结游戏画面，再激活截图覆盖层、解除鼠标限位并显示光标；退出时恢复光标显示计数。
- 诊断日志位于 `%LOCALAPPDATA%\weijie\logs\audit-dev-YYYY-MM-DD.log`，
  按 `traceId=shot-...` 可追踪热键、权限检查、抓屏、焦点交接和退出。
  `%LOCALAPPDATA%\weijie\app.log` 保留给现有回归脚本读取。

设置窗口打开时仍可截图，未保存的设置内容会保留；只有正在快捷键录入框中录入组合键时暂停触发。
「启用文字识别（主开关）」关闭后立即中止识别并退出本程序的 OCR 模型进程，
释放模型内存和显存，同时隐藏识别按钮；模型文件仍保留在磁盘。
关闭期间，图片翻译等入口也不会重新加载模型。翻译按钮仍独立显示，已有文字可直接翻译。
开启主开关并保存后，下次识别才按需重新加载模型；启用期间连续识别复用同一进程。
取消设置会恢复原来的开关权限，但不会预加载模型。组件缺失只在使用时提示，不阻止保存设置。

### 截图唤起速度

快捷键、托盘双击和快捷入口共用抓屏链路。D3D 设备按实际连接的显示适配器复用，
每次仍创建新的桌面复制会话并取得当前画面，不缓存旧截图，也不在空闲时持续抓屏。
适配器列表变化或设备失效时重新创建设备。

多屏轮流做非阻塞取帧，共享 300ms 等待预算，不为每个静止副屏串行等待 300ms；
单屏失败仍保留该屏的 GDI 基底，只有鼠标更新的通知不作为有效桌面图像。
窗口吸附探测在覆盖层出现前完成，首帧直接画出高亮，不再补一次全屏重绘。

本机单屏 2560×1440、每组 1 次首次抓屏加 5 次后续抓屏的测量：

| 抓屏阶段 | 优化前 | 优化后 |
|---|---:|---:|
| 首次抓屏 | 157ms | 157ms |
| 后续 5 次中位数 | 140ms | 62ms |
| 后续 5 次范围 | 125–156ms | 47–63ms |

该测量不包含进程启动、UAC 和窗口显示。首次抓屏仍需初始化显卡驱动；
300ms 是多屏等帧预算，不是驱动初始化、图像复制和窗口接管的总耗时上限。

诊断日志分别记录输入消息排队、设置权限、GDI、DXGI 设备准备、取帧复制、
窗口探测、创建显示、输入接管和首帧绘制，沿用同一截图 `traceId`。
运行 `Capture` 测试后，可单独测量抓屏，不弹出覆盖层或保存屏幕像素：

```bat
Release\Tests\capture_tests.exe "%CD%\Release\verification\latency" --benchmark
```

## 画笔与马赛克

选择画笔或马赛克后，鼠标进入选区会显示圆形笔刷光标：画笔使用当前颜色，
马赛克使用棋盘图案，并有深浅描边帮助辨认边缘。直径与工具面板的 `px` 一致，
按截图物理像素计算，高 DPI 下不会额外放大笔触。

调整尺寸会同步改变光标和后续笔迹，已有标注保持原尺寸。工具条、结果面板及选区外
恢复普通指针；尺寸预览由系统光标显示，不写入保存或复制的图片。

按住工具栏图标的右键并左右拖动即可调整大小，不再打开独立大小窗口：
左移减小、右移增大。八类标注工具共用这一操作，也支持在画布空白处按住右键调整。
右键按在已有图案上时优先选择或移动图案，不调整工具大小。
按下时在截图内显示轻量滑条、当前 `px` 和上下限；滑块逐像素跟随，整数数值不变时仍会移动。
松开右键确认并收起滑条；按 `Esc` 撤销本次调整，不退出截图。
离开工具条或覆盖层继续拖动仍有效；失去焦点、鼠标捕获转移或操作取消时释放捕获并恢复原尺寸。
滑条不进入保存或复制的图片，拖动只影响之后绘制的标注。颜色和透明度仍使用独立调色面板。

## 图案移动和重叠选择

矩形、椭圆、箭头、画笔、马赛克、文字、序号和表情统一支持右键拖动。
左键继续绘制或放置新图案，允许直接叠加在已有标注上；快速双击序号或表情可连续放置。

- 在图案上按住右键，移动超过 4 个逻辑像素后开始拖动；小幅手抖不移动图案。
- 原地右键单击选中图案，再次在同一位置右键单击，按从上到下的顺序循环选择重叠对象。
  选中后显示轮廓、类型及重叠次序；拖动优先移动已选中的对象，不会被上层对象抢走。
- 选择和移动不改变图层顺序、图案尺寸、编号或 GIF 帧时序。
  马赛克移动到新位置后从该位置的底图取样，不搬动原位置的图像内容。
- 方向键微调已选图案，`Shift` 加方向键使用较大步长；没有选中图案时仍调整截图选区。
- 每次拖动记为一步撤销/重做。拖动时 `Esc`、失焦、捕获转移或关闭截图会取消本次移动；
  原地单击选择不产生撤销记录。未拖动时按 `Esc` 先取消图案选择。

空心矩形和椭圆按边线命中，画笔、马赛克和箭头按实际轨迹命中；
图片按保持宽高比后的显示范围命中，缩放框中因宽高比而空出的边带不拦截其他对象。
选中轮廓和操作提示不进入保存、复制、贴图或 GIF 导出。

## 文字字号与光标

文字工具使用系统普通箭头，放置文字、输入、调整字号和点击工具条时都不显示放大的 I 形鼠标。
文字框内的输入竖线和中文输入法组合下划线按实际字体行高绘制，不改变鼠标的大小或点击位置。
已有文字保留原字号，鼠标与输入竖线不会写入保存或复制的图片。
移到编辑框边框、缩放控制点或旋转手柄时，仍显示相应的移动、拉伸或旋转指针。

### 拉伸、旋转和移动文字

文字输入时显示编辑框，拖动四角或四边的控制点，可独立调整文字的宽度和高度；
拖动顶部的圆形旋转手柄可自由旋转，旋转后控制点仍按文字自身方向工作。
输入期间调整后会继续保持可编辑状态。

按 Enter 或点击文字框外完成输入后，按住右键可拖动文字，不会移动截图选区。
右键单击或拖动文字只显示移动外框，不显示或响应拉伸、旋转控制点；
松开右键后仍保持移动选择，不自动重新进入文字编辑。双击文字后显示编辑控制点，
可重新输入、拉伸或旋转，原有拉伸和角度保留。
文字工具的普通左键在已有文字上也会新建输入框，不会误拖动原文字。

每次移动、拉伸、旋转和修改文字均可分别撤销/重做；拖动时按 Esc 撤销当前变换。
旋转框和控制点只用于编辑，不进入静态保存、复制、贴图或动态 GIF。
画笔、矩形等绘制工具可以正常画在文字上；右键移动已有文字不需要先切换工具。

## Emoji 表情

将图片放入主程序旁的 `images` 文件夹，点击工具栏的表情图标即可预览并选择。
程序只读取这个目录，不读取旧 `emoji` 或用户数据目录中的素材。
支持 JPG/JPEG、PNG、GIF、BMP、TIF/TIFF。GIF 贴图支持动画，悬停缩略图、落点虚影、
画布和贴图窗口均可播放。每次打开选择窗口重新扫描，窗口打开期间也会监听目录变化并自动刷新。
图片较多时可用滚轮、滚动条或 PageUp/PageDown 浏览；损坏图片跳过并记日志。

子文件夹就是图片分组，窗口按分组标题分别展示：

```text
images/
  default/       → 默认
  游戏/          → 游戏
  游戏/庆祝/     → 游戏/庆祝
  旅行/          → 旅行
  自定义.png     → 未分类
```

“默认”分组排在前面，“未分类”排在最后。分组内按文件名排序，空文件夹显示空分组；
删除图片后条目消失，删除子文件夹后整个分组消失。根目录没有图片时不显示“未分类”。
`images/default` 内的图片和整个目录均可自由删除，不会在下次启动、构建或部署时自动补回。

所有图片按软件设置的大小等比缩放，长边不超过当前设置对应的显示尺寸，
原图分辨率不会改变落地大小。透明背景保留，已放置的图片不因目录增删或排序变化而改变。
在表情图标上按住右键左右拖动，可调范围为 `12–256`；选择表情工具后在画布空白处也可调整。
修改大小只影响之后放置的表情，已有表情保持原尺寸。

安装版的素材目录为 `C:\Program Files\weijie\images`，向 Program Files 写入图片需 Windows 授权。
首次升级将现有的默认图标移到 `images/default`，保留已修改的图片和原有删除状态；
后续自动部署不补回素材、不重新分类用户放在根目录的图片。

### 保存动态 GIF 贴图

截图含动态贴图时，「保存」「另存为」会询问是否保存为动态图片：

- **是**：保存为 GIF，时长取最长贴图的一轮时长，短贴图按自身帧间隔循环播放。
  导出的整段动画循环播放，不使用截图界面当前播放位置作为起点。
- **否**：按设置或另存为所选的 PNG/JPG/BMP 保存，全部 GIF 贴图使用首帧。
- **取消**：保留编辑或预览，不写入文件。

普通截图、贴图窗口、长截图预览使用同一保存规则。`Ctrl+S` 保存到设置目录，
`Ctrl+Shift+S` 打开另存为。没有动态贴图时不弹动画询问；复制到剪贴板仍使用首帧静态图。

导出只写入一次完整背景，后续帧保存变化区域，区域内未变化的像素使用透明索引；
重复画面合并显示时长。
所有帧共享自适应 256 色调色板并使用 GIF 压缩，避免重复编码不动的截图区域。
GIF 的颜色精度与 PNG 不同，需要保留完整静态颜色时选择「否」并保存为 PNG。

## 序号与表情落点预览

选择序号或表情后，指针进入选区会显示随鼠标移动的半透明虚影。
虚影与点击后标注的大小、样式和中心位置一致，序号显示下一次要放置的数字，
悬停不会消耗编号；调整大小、颜色或更换表情后，预览同步更新。
表情在选择面板内松开鼠标时选定，返回选区即可预览，无需先点击画布。

虚影避开工具条、结果面板及弹窗，离开选区或切换窗口时隐藏，
不会进入保存或复制的图片。移动时复用预览位图，不重绘整张截图。

## 滚动截图

框选可滚动内容后点击「滚动截图」。自动滚动不再限制为 24 次或 20,000 像素；
页面连续三次没有继续滚动时结束，也可按 `Esc` 提前结束并预览已拼接内容。
目标窗口切换、后续画面无法匹配、达到 200 MiB 像素缓存或当前编码器 65,535 像素高度上限时，
会停止并保留已有长图，预览顶部显示结束原因。

- **保存**：读取当前设置的保存目录、格式和质量，自动生成不覆盖已有文件的名称；
  成功后在预览顶部显示实际保存路径，不弹出路径选择框。
- **另存为**：选择其他目录、文件名及 PNG / JPEG / BMP 格式，不更改设置中的保存目录。
- 保存失败或取消另存为不会关闭预览；剪贴板复制失败不会将已成功写盘的文件报告为保存失败。
- 超长图片建议使用 PNG。超过 JPEG 尺寸上限时，
  预览会提示改用 PNG 或 BMP，不会丢弃长图。

## 回归测试

`Lifecycle` 使用受控测试进程验证空闲卸载、忙时中断、关闭后禁止重载及重新开启后的懒加载，
不依赖下载真实模型。`GPU` 测试另行验证实际模型推理后关闭进程、重新加载和再次释放。

`Capture` 是独立的实屏测试，会创建 D3D11 窗口并切换焦点，无需 OCR 组件。
当前前台应用权限高于测试进程时，仅验证桌面取帧，并明确跳过输入接管测试；
完整验证应在同等权限的终端运行。原始键盘包测试覆盖解析与分发，游戏内物理热键需实机验证。

## 开机以管理员权限启动

在设置中勾选「开机自动启动（管理员权限）」并保存，或使用托盘中的同名开关。
微截会注册当前用户的登录计划任务，以最高权限在交互桌面运行；不保存账号密码，
无需关闭 UAC。启动发生在用户登录后，而不是登录界面之前。

- 已开启旧版注册表开机启动的用户，下次启动新版时会自动转换为管理员登录任务。
- 关闭开关会删除微截的登录任务和旧版启动项，不会退出当前正在运行的实例。
- 先把程序放在长期使用的固定目录，再开启自动启动；移动后重新勾选开关以更新程序路径。
- 笔记本电池供电不会禁止启动或停止程序，常驻进程不受计划任务默认运行时限影响。
- 手动启动仍需要 Windows UAC 授权；已授权配置的登录计划任务负责后续登录时的管理员启动。
- 开关状态以实际计划任务为准；注册或删除失败会显示原因，不会静默报告成功。
